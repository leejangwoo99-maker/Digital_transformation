# Digital transformation
  - Dash board

1. The preprocessed data was stored in a DB server, then mined for machine learning training, and finally visualized using winform of C#.NET.
> 전처리된 데이터는 DB 서버에 저장된 후, 머신러닝 학습을 위해 마이닝되었고, 최종적으로 C#.NET WinForm을 사용하여 시각화되었습니다.
2. According to 사양서 & Architecture, the characteristics of the files are indicated.
> 사양서 및 아키텍처에 따라 파일의 특징이 명시되어 있습니다.
3.Others are jupyter notebooks related to the data mining and demon programs.
> 기타 파일은 데이터 마이닝 및 데모 프로그램 관련 Jupyter Notebook입니다.
4. Applied Machine learning algorithms are Euclidean Distance, Cosine Similarity and LightGBM.
> 적용된 머신러닝 알고리즘은 유클리드 거리, 코사인 유사도, LightGBM입니다.
5. C#_Dashboard folder is the Front-end GUI, FYI, 'app' folder is FastAPI Framework + Streamlit.
   According to the environment, choose one between them.
> C#_Dashboard 폴더는 프런트엔드 GUI이며, 'app' 폴더는 FastAPI 프레임워크와 Streamlit을 사용합니다.
> 환경에 따라 둘 중 하나를 선택하십시오.
6. If want to know the related documents, search for the details from the link below.
> 관련 서류는 아래 링크에서 확인하십시오.
> https://serious-ambert-bc0.notion.site/APTIV-31d8bc55235b80f58ecff4b949efdbdf?source=copy_link
7. FYI, demon & back-end & streamlit are compiled by Nuitka, please refer Nuitka folder.
> 참고로, demon, back-end, streamlit은 Nuitka로 컴파일되었습니다. Nuitka 폴더를 참고하세요.
8. Recommend relearning algorithm once a year at the time of the inventory count, if use the data for 6months, it will take 6days to finish learning algorithm.
> 재고 조사 시점에 맞춰 연 1회 알고리즘 재학습을 권장합니다. 6개월치 데이터를 사용할 경우, 학습 완료에 6일이 소요됩니다.
